Hosting for independents

Deplay publishes your sites and APIs from GitHub, or a simple file upload, with a public address in seconds. No server to manage.

Get started

$git clone <your-repo> · import into Deplay

What Deplay handles for you

Source code

Private GitHub repositories, branches and commit history. A build triggers on the branch you choose.

Uploaded files

No Git repository needed: a folder or a zip archive, uploaded directly and published in seconds.

Environment variables

Encrypted per project, injected at build and at runtime. Import from a .env file or paste them directly.

Logs and usage

Build logs, live runtime output, traffic and storage — all visible from the dashboard.
