DEPLAY DEPLAY

Hébergement pour indépendants

Deplay publie vos sites et vos API depuis GitHub, ou un simple dépôt de fichiers, avec une adresse publique en quelques secondes. Aucun serveur à gérer.

Commencer

$git clone <votre-dépôt> · importer sur Deplay

Ce que Deplay gère pour vous

Code source

Dépôts GitHub privés, branches et historique de commits. Un build se déclenche sur la branche que vous choisissez.

Fichiers déposés

Sans dépôt Git : un dossier ou une archive zip déposée directement, publiée en quelques secondes.

Variables d'environnement

Chiffrées par projet, injectées au build et à l'exécution. S'importent depuis un fichier .env ou se collent directement.

Logs et usage

Journaux de build, exécution en direct, trafic et stockage — tout reste visible depuis le tableau de bord.
