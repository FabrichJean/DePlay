Runtimes

A Deplay web service runs in one of these two runtimes. The image, install command and start command are the ones actually used by the worker.

Node.js

node:22-slim
$npm install
  • For an Express, Fastify, Hono API, or any Node server listening on the PORT variable.
  • The repository folder is mounted as-is in the container, nothing is copied beforehand.
  • Restarts automatically if the process stops.
Image
docker.io/library/node:22-slim
Install
npm install
Start
node server.js
Memory
1 GB
CPU
1

Python

python:3.12-slim + ffmpeg
$pip install -r requirements.txt
  • For a FastAPI, Flask API, or any ASGI/WSGI server listening on the PORT variable.
  • ffmpeg is installed in the image, for audio and video processing.
  • Packages install into /work/.pylocal (PYTHONUSERBASE), specific to each project.
Image
localhost/deplay-python:3.12-ffmpeg
Install
pip install -r requirements.txt
Start
python -m uvicorn main:app --host 0.0.0.0 --port $PORT
Environment variables
PYTHONUSERBASE, PYTHONDONTWRITEBYTECODE
Memory
1 GB
CPU
1
