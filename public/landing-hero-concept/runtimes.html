Runtimes

Un web service Deplay tourne dans l'un de ces deux runtimes. L'image, la commande d'installation et la commande de démarrage sont celles réellement utilisées par le worker.

Node.js

node:22-slim
$npm install
  • Pour une API Express, Fastify, Hono, ou tout serveur Node qui écoute sur la variable PORT.
  • Le dossier du dépôt est monté tel quel dans le conteneur, rien n'est copié au préalable.
  • Redémarre automatiquement si le processus s'arrête.
Image
docker.io/library/node:22-slim
Installation
npm install
Démarrage
node server.js
Mémoire
1 Go
CPU
1

Python

python:3.12-slim + ffmpeg
$pip install -r requirements.txt
  • Pour une API FastAPI, Flask ou tout serveur ASGI/WSGI qui écoute sur la variable PORT.
  • ffmpeg est installé dans l'image, pour les traitements audio et vidéo.
  • Les paquets s'installent dans /work/.pylocal (PYTHONUSERBASE), propre à chaque projet.
Image
localhost/deplay-python:3.12-ffmpeg
Installation
pip install -r requirements.txt
Démarrage
python -m uvicorn main:app --host 0.0.0.0 --port $PORT
Variables d'environnement
PYTHONUSERBASE, PYTHONDONTWRITEBYTECODE
Mémoire
1 Go
CPU
1
